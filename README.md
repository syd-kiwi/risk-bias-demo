# Quality Assessment and Risk of Bias Tool Repository

[View the website](https://syd-kiwi.github.io/risk-bias-demo/) · [About the authors](https://syd-kiwi.github.io/risk-bias-demo/authors.html)

A searchable collection of assessment tools by Leila Ledbetter and Stephanie Hendren.

## How to update the tools

You only need Excel and a GitHub account with permission to update this repo.

1. Open the website and click **Download source spreadsheet**. Keep a backup.
2. Open it in Excel and edit the tools in **Sheet1**.
3. Save it with the exact filename **source-workbook.xlsx**.
4. Open [the repo](https://github.com/syd-kiwi/risk-bias-demo), select **Code**, and make sure the branch says **main**.
5. At the top-level file list, click **Add file → Upload files** and upload your updated spreadsheet.
6. Add a short message describing your changes, select **Commit directly to main** if offered, and click **Commit changes**. This saves your update.
7. Wait a few minutes, then refresh the website and check a tool you changed.

The website reads the spreadsheet automatically. No coding is needed. If GitHub requires a pull request, ask the repo owner to approve and merge it.

## Keep these things the same

- Keep the filename **source-workbook.xlsx**, the sheet name **Sheet1**, and all column headings.
- Keep each tool’s rows together. Extra study types go below the tool with the name cell blank. Delete the full group of rows when removing a tool.
- Get Leila’s approval before adding new tools.
- For link changes, update Excel’s underlying hyperlink as well as its displayed text.
- Only **Sheet1** appears on the website.

## If something goes wrong

Check the filename, sheet name, and headings. If the website still looks unchanged, wait a few minutes and refresh again.

To undo a mistake, upload your backup using the same filename and steps above. Ask the repo owner for help with access, author bios, photos, or design changes.
